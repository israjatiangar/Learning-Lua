# Learning Lua through CLI Tools

A collection of beginner-friendly command-line tools built to learn Lua by
creating practical software rather than solving abstract coding puzzles.

## Why Lua?

Because it is small, simple, and dare I say easy. I love its English-like,
minimalistic syntax. The fact that it isn't an indentation/whitespace-based
syntax is a major plus point in my book.

## Current Project

- **Tasker(Todo app)** (`tasker/Main.lua`) - A simple terminal-based todo app
  generic, but quite good for learning to do functions, daving file reading
  files and getting the hang of the language.
